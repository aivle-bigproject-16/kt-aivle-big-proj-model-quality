## 3. 해석

### 3.1 지문 가설은 빗나갔다

사전 예측: *"`ct_cell_alignment_failure`가 crop 후 LANCZOS로 원본 raster에 되돌리므로
(v1.9 §2.2.1) 리샘플 링잉이 FAIL에만 남고, 모델이 그것을 배웠을 것"*

측정 결과 이 예측은 **지지되지 않았다**.

- 지문 피처(방사평균 파워스펙트럼 기울기 + 고주파 꼬리) **2개만** 쓴 대조군: **0.2679**
- `ct_acquisition_motion`은 **0.016**으로 사실상 0
- 지문 피처를 완전히 제거해도 0.9969 → 0.9782로 거의 하락 없음

→ **스펙트럼 지문은 높은 점수의 원인이 아니다.**

단, 이는 "지문이 없다"가 아니라 **"이 프록시로는 검출되지 않는다"** 는 뜻이다.
파워스펙트럼 기울기 2개가 리샘플 흔적을 충분히 포착하는지는 별도로 검증되지 않았다.

### 3.2 훨씬 중요한 발견 — 규칙이 MobileNet을 이겼다

손으로 만든 피처 16개 + GBM이 **0.9969**로 MobileNet의 **0.9782**보다 높다.
케이스별로도 5종 중 4종이 1.000이다.

이는 설계문서(0724) §6-2의 예측과 정확히 일치한다.

> *"합성 FAIL이 전역왜곡 위주라 규칙 baseline이 의외로 셀 수 있음 → 먼저 재보는 게 값쌈."*

그리고 PLAN.md §2-a에서 v1.9 사양을 읽고 도출한 근거와도 맞는다.
**각 실패 케이스의 자동 통과 조건이 곧 판별식**이고, 게이트를 통과한 이미지만
데이터셋에 남았으므로, 그 조건식을 피처로 역산하면 잡히는 것이 당연하다.

사용한 피처(v1.9 §2.2에서 역산):

| 피처 | 대응 케이스 | v1.9 근거 |
|---|---|---|
| 평탄부 noise σ, edge SNR | `ct_low_signal_noise` | §2.2.4 "균일 영역 σ↑, edge SNR 20~65%↓" |
| 고주파 edge energy, HF/LF 비 | `ct_insufficient_projection_sampling` | §2.2.3 "고주파 edge energy 20~65% 감소" |
| gradient 자기상관 부엽(12~34px) | `ct_acquisition_motion` | §2.2.2 "512공간 18~28px ghost offset" |
| cupping 상관, gradient 이방성 | `ct_beam_hardening_metal_streak` | §2.2.5 "넓은 cupping + 방사 streak" |
| 전경 비율, 프레임 접촉률 | `ct_cell_alignment_failure` | §2.2.1 "outline 잔여율 0.50~0.90" |

### 3.3 LogReg가 0.55에 그친 것이 해석을 뒷받침한다

동일 피처로 선형 모델은 0.5545에 그친다. gate 조건이 *"0.40~0.70 구간"* 같은
**구간(양쪽 경계) 조건**이라 선형 결정경계로는 표현되지 않고, GBM이 구간을 학습해야 한다.
합성 데이터의 구조가 그대로 드러난 결과다.

### 3.4 그래서 결론이 뒤집힌다

높은 점수의 원인은 지문이 아니라 **문제 자체가 합성 때문에 너무 쉽다는 것**이다.

실제 촬영 실패는 강도가 연속적으로 퍼져 있고 약한 실패와 정상의 경계가 모호하다.
반면 합성 FAIL은 각 케이스의 gate가 강도를 좁은 구간으로 **강제**했기 때문에
PASS와 깔끔하게 갈라진다. 약한 FAIL(경계 사례)이 데이터에 거의 없다.

## 4. 실무적 함의

### 4.1 MobileNet이 필요한지 재검토해야 한다

| | 규칙 GBM | MobileNetV3-Small |
|---|---|---|
| TEST recall@FPR3% | **0.9969** | 0.9782 |
| 학습 시간 | 수십 초 | 약 25분 (CPU, 3 epoch) |
| 해석 가능성 | **어떤 피처가 어떤 케이스를 잡는지 설명 가능** | 불투명 |
| 추론 비용 | 매우 낮음 | 장당 수십 ms |

현재 데이터에서는 딥러닝의 이점이 관측되지 않는다.
다만 규칙은 **알려진 5개 케이스에 맞춰 설계된 피처**에 의존하므로,
사양에 없는 새로운 촬영 실패 유형에는 대응하지 못할 가능성이 있다.
그 점은 MobileNet이 유리할 수 있으나, 현재 데이터로는 검증 불가하다.

### 4.2 실촬영 FAIL 확보가 유일한 판별 수단이다

규칙이 이겼다는 것은 "합성 데이터에서 잘 통한다"는 뜻일 뿐,
실제 촬영 실패에도 통한다는 근거가 아니다.
**실촬영 나쁜 샷을 소량이라도 확보하기 전까지 어떤 숫자도 실배포 성능의 근거가 되지 않는다.**

## 5. 이 결과의 한계

1. **단일 fold** — test가 셀 7개뿐이다. 0.9969와 0.9782의 차이가 유의한지 알 수 없다.
   CT 독립 표본이 47개라는 제약이 그대로 드러난 부분이다.
2. **MobileNet은 3 epoch에서 중단** — 지표 포화로 중단했으나, 더 돌렸을 때의
   일반화 변화는 측정하지 않았다.
3. **지문 프록시가 F6 하나뿐** — F1(히스토그램 구멍)·F2(고정색)는 RGB 전용이라
   CT에는 적용되지 않는다. CT 고유의 다른 지문 축은 아직 설계하지 않았다.
4. **lockbox 미개봉** — 최종 확인은 아직 하지 않았다(의도된 상태).
