# 골든 fixture — 촬영 품질 분류기 (CT)

`ai-infer` 가 학습 노트북과 **같은 입력에 같은 출력**을 내는지 자동 검증하는 표본입니다.

## 구성
- 이미지 24장 (FAIL 12 / PASS 12)
- FAIL 은 5개 실패 케이스에 고루 분포하며 **가장 점수가 낮은(어려운) 것**을 포함합니다
- PASS 절반은 **판정선 근처**의 것이라 전처리 오류에 민감합니다

## 검증 방법
1. `images/` 의 각 파일을 추론 파이프라인에 그대로 넣습니다 (**ROI 자르기·리사이즈 추가 금지**)
2. 나온 logit 을 `expected.json` 의 `expected.logit` 과 비교합니다
3. **|Δ| <= 1e-3 이면 통과.** 벗어나면 전처리가 다릅니다

`label` 은 threshold 1.652190 기준입니다. threshold 를 바꾸면 label 도 달라지므로,
**logit 값으로 검증**하십시오.

## 흔한 실패 원인
- 정사각 리사이즈 (올바른 값: 288x512 letterbox, 여백 114)
- 흑백 변환 없이 RGB 로 읽음
- ImageNet 정규화 누락
- BGR/RGB 뒤바뀜
